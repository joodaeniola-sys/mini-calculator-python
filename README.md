# Mini Calculator
A simple command-line calculator built with Python.
# Features
- Addition
- Subtraction
- Multiplication
- Division
- Looped calculations
- Invalid operator detector
- User-controlled exit
# Python Concepts Used
- User input with 'input()'
- Type conversion with 'float'
- 'while' loops
- 'if / elif / else' statements
- Arithmetic operators
- String methods
- 'break
# HOW TO RUN
1. Make sure Python is installed.
2. Run 'MiniCalculator.py'.
3. Enter two numbers and choose an operator.
4. Choose whether to continue.
# What I learned
This project helped me practice loops, conditional statements, user inputs, type conversion, and controlling program termination.
